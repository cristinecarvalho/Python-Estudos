# Python-Estudos 🐍

Repositório criado para acompanhar meus estudos e minha evolução em Python.

Aqui organizo exercícios, práticas e pequenos desafios desenvolvidos ao longo dos meus estudos da linguagem.

## 📚 Conteúdos

O repositório vai inclui exercícios sobre:

- Variáveis e tipos de dados
- Operadores aritméticos
- Estruturas condicionais
- Estruturas de repetição
- Exercícios com `for`
- Exercícios com `while`
- Lógica de programação
- Resolução de problemas

Novos conteúdos serão adicionados conforme avanço nos estudos.

## 🎯 Objetivo
Consolidar os fundamentos, desenvolver raciocínio lógico e preparação para:
- Projetos para ciência de dados
- Desafios técnicos
- Exercícios de plataformas como HackerRank
- Projetos pessoais
